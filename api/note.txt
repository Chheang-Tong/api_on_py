====> Virtual Enviroment <=====
# 1. Create a virtual environment in your project folder
python3 -m venv venv

# 2. Activate the virtual environment
source venv/bin/activate

# 3. Install Flask inside this environment
pip install flask

# 4. Run your app
python backend.py

# 5. you can deactivate the environment
deactivate

====> Brew install Flask <=====
Brew install Flask && python3 backend.py
